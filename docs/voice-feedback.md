# 离线中文录制提示

声音候选保持0.2.11包版本，通过完整提交区分，不覆盖公开正式版本。默认关闭；设备服务环境OPENARIA_VOICE_ENABLED=1开启，OPENARIA_VOICE_DEVICE指定ALSA播放PCM，默认plughw:CARD=duplexaudio,DEV=0。可通过服务drop-in关闭并重启空闲服务。

设备端真实启动成功播放开始录制，正常停止并提交保存状态后播放录制已保存；启动失败、运行故障和保存失败分别提示。实体按钮、网页及定时停止共用协调器。重复幂等请求不重播成功音。短时间连续状态变化会丢弃未播放的旧提示，不保证每次点击均有声音。safe-swap路径不播保存成功音。

固定WAV使用用户试听确认的zh-CN-XiaoxiaoNeural普通话女声预生成，24kHz单声道PCM，随包离线提供；运行时仅依赖/usr/bin/aplay。串行后台播放，5秒超时后杀死播放进程，记录失败并继续。声音错误不抛入录制流程，提示队列有界且过期即丢弃。关闭服务不承诺播完尾音；断电无法播报。日志播放成功仅证明ALSA接受播放，不证明扬声器可听；网页仍是状态反馈来源。

开始提示可能进入麦克风。实机必须检查外接扬声器、音量和录放并行；相机缺失时只能验证拒绝录制提示，不能声称录制全链路通过。网页可调提示音量，但未增加服务启用开关或状态灯故障提示。


录制页的“提示音量”支持0–100%，0为静音。设备待机时保存，用于之后的提示音；不改变
已经播放中的声音。默认100%保持当前提示音原始幅度，最高音量仍取决于设备硬件音量。
音量通过独立播放线程缩放PCM16样本，不修改ALSA混音器或麦克风增益，也不阻塞录制起停。

GET/POST `/api/v4/voice` 返回 `ylx.voice.v1`（enabled、volume）；写入使用
`ylx.voice-set.v1` 和整数volume。设置保存在 state.sqlite3 的 voice_feedback 文档中，
写入成功才更新内存值，重启后读取；录制/封存时拒绝修改。沿用鉴权、Origin与CSRF校验。
声音服务未启用或旧固件没有接口时，网页隐藏入口。保存错误明确显示，不提前显示成功。

校时提示沿用晓晓音色：首次客户端校时成功“设备就绪”，服务端拒绝未校时开始时“请打开手机页面校准时间”。同样遵循启用和音量设置，静音时仅网页反馈。
