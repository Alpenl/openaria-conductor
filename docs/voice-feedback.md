# 离线中文录制提示

声音候选保持0.2.11包版本，通过完整提交区分，不覆盖公开正式版本。默认关闭；设备服务环境OPENARIA_VOICE_ENABLED=1开启，OPENARIA_VOICE_DEVICE指定ALSA播放PCM，默认plughw:CARD=duplexaudio,DEV=0。可通过服务drop-in关闭并重启空闲服务。

设备端真实启动成功播放开始录制，正常停止并提交保存状态后播放录制已保存；启动失败、运行故障和保存失败分别提示。实体按钮、网页及定时停止共用协调器。重复幂等请求不重播成功音。短时间连续状态变化会丢弃未播放的旧提示，不保证每次点击均有声音。safe-swap路径不播保存成功音。

固定WAV使用用户试听确认的zh-CN-XiaoxiaoNeural普通话女声预生成，24kHz单声道PCM，随包离线提供；运行时仅依赖/usr/bin/aplay。串行后台播放，5秒超时后杀死播放进程，记录失败并继续。声音错误不抛入录制流程，提示队列有界且过期即丢弃。关闭服务不承诺播完尾音；断电无法播报。日志播放成功仅证明ALSA接受播放，不证明扬声器可听；网页仍是状态反馈来源。

开始提示可能进入麦克风。实机必须检查外接扬声器、音量和录放并行；相机缺失时只能验证拒绝录制提示，不能声称录制全链路通过。未增加网页开关或状态灯故障提示。
