# Open Aria 设备使用指南

本指南面向使用 Open Aria 设备进行双目视频、音频和 IMU 同步录制的现场用户。
设备端运行 Open Aria Conductor，浏览器中的控制页面称为 Echo / Web。

当前版本适用于 D-Robotics RDK X5 V1.0 和 YLX 2UQ2。设备即使没有连接相机也能启动、
联网并打开管理页面，但必须接入受支持的相机后才能开始录制。

## 快速信息

| 用途 | 地址或凭据 |
| --- | --- |
| 局域网 Web 地址 | `http://rp-ylx.local:8080/` |
| 设备热点名称 | `OpenAria-XXXXXXXX`，后缀因设备而异 |
| 设备热点密码 | `12345678` |
| 热点模式 Web 地址 | `http://10.42.0.1:8080/` |
| SSH 管理账号 | `OpenAria` |
| SSH 管理密码 | `123456` |

热点密码和 SSH 密码不是同一个密码。Linux 账号名称区分大小写，必须写成
`OpenAria`。

## 1. 启动设备并打开页面

1. 接好设备电源和相机，并确认管理员已经配置固定的 `/data` 存储根目录。
2. 等待 RDK X5 完成启动。
3. 使用电脑或手机连接设备所在的局域网，或者连接设备热点。
4. 在浏览器地址栏输入管理地址。

设备已经连接到局域网时，优先打开：

```text
http://rp-ylx.local:8080/
```

设备没有可用局域网连接时，连接名称形如 `OpenAria-XXXXXXXX` 的热点，密码为
`12345678`，然后打开：

```text
http://10.42.0.1:8080/
```

浏览器必须使用 `http://` 并保留端口 `8080`。热点连接可能被电脑或手机标记为
“无互联网”，这是正常现象。请选择继续连接，不要让系统自动切回其他网络。

完整的 Wi-Fi 切换和失联恢复方法见[网络连接与救援指南](networking.md)。

## 2. 认识控制页面

控制页面的主要区域如下：

- 顶部连接方式：显示 `Wi-Fi`、`设备热点` 或 `有线`。点击它可以打开网络设置。
- 中间预览：显示设备当前的双目取景画面和相机状态。
- 底部录制区：填写可选名称、开始或结束录制，并显示时长、帧数、写入量和校验进度。
- 会话台账：查看已经封存或未成功的录制会话。
- 设备与链路：查看相机、存储、网络和当前会话状态。

控制页面断开不等于设备已经停止录制，也不构成中断恢复承诺。重新建立正常连接后，应先查看
设备当前状态，不要在状态不明时重复发送开始或结束命令。0.5 不验收网络或浏览器中断后的
自动恢复或继续传输。

## 3. 开始录制

开始前确认：

- 页面已连接到设备，预览能够更新；
- 相机状态不是“相机未接入”；
- 存储状态可写；
- 设备当前没有其他录制任务；
- 不需要在录制期间切换 Wi-Fi 或热点。

操作步骤：

1. 在底部的“录制名称（可选）”中填写便于识别的名称，也可以留空。
2. 点击底部的圆形录制按钮。按钮的操作名称为“开始录制”。
3. 页面显示当前会话名称、会话 ID、录制时长、帧数和写入量后，表示录制已经开始。

名称留空时，设备会按本地真实时间生成名称，例如：

```text
录制 2026-08-25 16:17:08
```

默认名称使用设备本地时间。如果时间明显不正确，应先让管理员检查设备时钟和时间同步，
否则自动生成的名称也会不正确。

录制期间不要直接断电、卸载 `/data`、终止服务或修改网络。浏览器预览只是控制和观察入口，
录制数据由设备独立写入；意外掉电、进程终止或操作中断后的恢复不属于当前支持范围。

## 4. 结束并确认录制

1. 点击底部的录制按钮，此时按钮的操作名称为“结束录制”。
2. 等待设备结束写入、封存并完成校验。
3. 打开顶部的“会话台账”。
4. 确认新会话显示为“已封存”，并优先确认消费方判断为“可用”。

点击会话可以查看时长、帧数、丢帧、文件清单和校验结果。只有设备判定为可下载、且消费方
独立校验为可用的会话，页面才会显示有效的下载入口。

不要把“已封存”和“已验证可用”理解为同一个状态：

- “已封存”表示设备已经完成本次录制并写出完整清单；
- “可用”表示页面读取到的实际文件通过了独立校验；
- “未成功”表示录制没有正常形成可交付会话，应保留现场状态并交给管理员检查。

## 5. 查找和下载历史会话

1. 点击顶部的“会话台账”。
2. 使用“全部”“已验证可用”或“未成功”筛选会话。
3. 可以按录制名称或会话 ID 搜索。
4. 点击某个会话查看详情。
5. 对已验证可用的会话，按文件清单逐项下载所需数据。

大文件下载期间应保持电脑和设备在同一网络中。切换 Wi-Fi、热点或关闭设备会中断正在进行的
下载。

## 6. 相机未接入时

没有相机不会阻止系统启动，也不会影响以下功能：

- 打开 Web 管理页面；
- 查看和修改网络；
- 查看设备与存储状态；
- 浏览已经存在的会话；
- 通过 SSH 维护设备。

页面会明确显示“相机未接入”，并禁用“开始录制”。接好相机后，设备通常会自动恢复预览和
录制入口，不需要重启服务。如果相机已经接好但状态长时间没有恢复，请先检查 USB 接头和供电，
再查看“设备与链路”中的相机状态。

## 7. 固定存储与 LAN 交付

当前 0.5 只向部署配置的固定 `/data` 根目录写入。产品不规定真实 TF `p3` 分区，不支持把
录制盘作为可移除介质使用，也不提供“安全换盘”操作。不要在设备运行期间拔出、替换或卸载
承载 `/data` 的存储。

完成录制时，应使用页面正常结束并等待会话封存。已成功封存的会话通过同一局域网下载或由
Open Aria Bridge / Desktop 导入。强制制造 ENOSPC 或 inode 耗尽，以及从掉电、进程终止或
中断的录制、下载和发布中恢复，都不属于当前验收范围。现场应预留足够空间，并以正常开始、
正常结束和 LAN 交付作为受支持流程。

## 8. 正常关机和重启

设备当前没有提供 Web 关机按钮。需要关机或重启时，先结束录制并等待封存完成，然后通过
SSH 操作。热点模式下的登录命令是：

```bash
ssh OpenAria@10.42.0.1
```

局域网模式可以使用：

```bash
ssh OpenAria@rp-ylx.local
```

登录密码为 `123456`。正常关机：

```bash
sudo systemctl poweroff
```

正常重启：

```bash
sudo systemctl reboot
```

`sudo` 使用同一个密码 `123456`。执行关机后，应等待系统完全停止再切断电源。

## 9. 常见问题

### 页面打不开

- 确认输入的是 `http://`，不是 `https://`；
- 确认地址末尾包含 `:8080`；
- 热点模式使用 `10.42.0.1`，局域网模式不能继续使用这个热点地址；
- 关闭可能拦截内网地址的 VPN、代理或浏览器安全扩展；
- `.local` 地址无法解析时，改用设备当前局域网 IP，或进入热点后使用固定地址。

### 开始录制按钮不可用

常见原因包括相机未接入、存储不可写、页面与设备事件流断开、已有录制正在运行，或者设备正在
处理上一个命令。打开“设备与链路”查看具体状态，不要连续重复点击录制按钮。

### 切换网络后页面断开

这是正常现象。设备的网络已经变化，原来的浏览器连接不能跨网络继续使用。让电脑或手机加入
设备切换后的网络，再用新地址重新打开页面。具体步骤见[网络连接与救援指南](networking.md)。

### 页面显示上一次录制没有成功封存

不要删除录制目录、重新格式化存储设备或继续反复录制。保留设备和存储现状，记录页面显示的
会话 ID，并请管理员查看运行日志。

## 10. 使用范围和安全说明

设备热点、SSH 账号和密码是固定的，设计用途是受信任的内部网络。不要把设备的 `8080` 和
`22` 端口直接暴露到公网，也不要在不受信任的公共网络中使用这些固定凭据。
