## 零、设计约定（非 Bug，后续审查豁免）

以下 3 项属于 Miro-Ego 0.3.0 当前阶段有意保留的设计/约定，**不属于待修复缺陷**，在 `0.3.0` 及其后置 Backlog 正式交付前无需反复告警或改动：

1. **救援热点默认 WPA2 口令 `"12345678"`**（`crates/miro-ego-network/src/nmcli.rs`、`controller.rs`）：单机离线开箱/救援热点 `MiroEgo-XXXXXXXX` 的固定初始口令为产品设计约定。
2. **`miro-ego-device-login` 硬编码 `MiroEgo` 管理员密码哈希**（`deploy/miro-ego/miro-ego-device-login`）：用于固化 RDK X5 运维账户 `MiroEgo` 的既定 sudo 登录凭据。
3. **默认开发 Ed25519 签名种子回退**（`crates/miro-ego-deploy/src/bundle.rs`、`tools/miro_ego_host/factory_recovery/provision.py`）：`MIRO_EGO_RELEASE_PUBLIC_KEY_HEX` 未在编译期注入时回退至默认开发种子（签名发布渠道已明确规划至 0.3.0 后 Backlog），**禁止**在未提供该环境变量时触发 `compile_error!` 阻断常规开发/CI 构建。
