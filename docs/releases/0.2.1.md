# v0.2.1

## 新增

- 网页顶部显示设备版本，提供检查更新、发布说明、确认升级与上一版本回退。
- 独立设备更新服务执行 OSS 整包更新，保存任务结果；浏览器关闭或服务重启后可以继续查询。
- 录制与更新共用维护锁，升级期间禁止网页、客户端或实体按钮开始新录制。

## 发版规则

- Conductor、Rust 包、Echo Web 和设备安装包统一为 0.2.1。
- 后续仅递增 0.2.x。附注标签、构建身份和包版本必须一致。
- 普通 push/PR 仅构建；正式附注标签发版通过检查后发布 GitHub Release 与国内 OSS 渠道。

## 升级说明

旧固件没有网页更新接口，需要先执行一次 `sudo openaria-update` 安装带该功能的版本。
后续可以直接从“版本与更新”操作。更新应在录制与封存完成后进行，服务自动重启。
保留录制数据；回退使用本机上一版本，不回滚已录制数据。此功能不代表整机系统升级或物理掉电验收。
