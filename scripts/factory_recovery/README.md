# OpenAria 一键刷机工具

安装 requirements.txt 后运行 recover.py。推荐菜单1备份配置、菜单0准备镜像、菜单5一键刷机。
系统、离线软件、配置一次写入，装回原地瓜派后开机自动恢复并重启一次。

菜单5默认创建16 GiB ext4系统区和占满剩余空间的exFAT录像区（另保留官方CONFIG引导区）。
电脑读卡时打开 `RECORDINGS/recordings`。需要新版固件，首次初始化与断电稳定性仍待实机验收。

快速刷写不清除镜像范围外的旧数据。配置包绑定原板子，备份密码不要放在卡上。
完整说明见 [使用说明](../../docs/factory-recovery.md)。自动首次启动仍待地瓜派实机验收。
